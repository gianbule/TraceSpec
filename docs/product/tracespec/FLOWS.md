# User Flows — TraceSpec

## FLOW-01 — Discover an idea
1. User memasukkan ide.
2. Sistem merangkum problem, user, outcome, dan constraint.
3. Sistem meminta klarifikasi bila perlu.
4. User mengonfirmasi konteks.
5. Sistem membuat project profile.

## FLOW-02 — Challenge and lock MVP
1. Sistem menampilkan hypothesis, scope MVP, non-goals, asumsi, dan risiko.
2. User menerima, mengubah, atau menunda scope.
3. Sistem menyimpan keputusan scope.

## FLOW-03 — Generate specification
1. User memilih generate blueprint.
2. Sistem membuat PRD, features, assumptions, decisions, dan metrics.
3. Sistem menjalankan traceability audit.
4. User meninjau output.

## FLOW-04 — Generate build packet
1. User memilih feature/milestone.
2. Sistem memecah requirement menjadi task.
3. Sistem membuat test dan agent prompt.
4. User menyetujui packet untuk digunakan coding agent.

## FLOW-05 — Revise a requirement
1. User memasukkan change request.
2. Sistem membuat impact analysis.
3. User menyetujui/reject/defer.
4. Sistem memperbarui artefak terdampak dan changelog.
