# TraceSpec Plan

## Arsitektur workflow

`Capture → Discover → Challenge → Specify → Visualize → Slice → Validate → Package → Approve → Version → Learn`

## Milestone

| Milestone | Outcome | Feature |
|---|---|---|
| M0 Foundation | Konvensi ID, struktur file, project context | FEAT-01 |
| M1 Discovery | Idea Canvas, clarification, Challenge Mode | FEAT-01, FEAT-02 |
| M2 Specification | PRD, assumptions, decisions, metrics | FEAT-03 |
| M3 UX Blueprint | Flow, screens, design brief | FEAT-04 |
| M4 Build Handoff | Task, test, build packet, agent prompt | FEAT-05 |
| M5 Change Control | Trace audit, impact analysis, GitHub versioning | FEAT-06, FEAT-07 |

## Definition of Ready

Milestone hanya siap diberikan ke coding agent bila requirement disetujui, scope in/out jelas, dependencies diketahui, test tersedia, dan tidak ada `[TRACE GAP]` kritis.
