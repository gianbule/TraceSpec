# TraceSpec

**From idea to build-ready product, with every decision connected.**

TraceSpec adalah AI Product-to-Build Orchestrator untuk solo builder, founder, mahasiswa, dan tim kecil. Ia mengubah ide menjadi PRD, UX flow, screen inventory, task engineering, test plan, dan build packet untuk AI coding agent.

## Prinsip

1. Mulai dari problem dan outcome, bukan UI.
2. Kunci MVP sebelum coding.
3. Hubungkan problem → goal → requirement → flow → screen → task → test.
4. Catat asumsi dan keputusan secara eksplisit.
5. Analisis dampak sebelum revisi.
6. Gunakan build packet kecil, bukan satu prompt besar.

## Struktur

- `docs/product/tracespec/`: source of truth produk
- `design/tracespec/`: handoff UX dan wireframe
- `prompt-generator/`: template dan kontrak prompt global
- `prompts/tracespec/`: prompt spesifik proyek
- `build-packets/tracespec/`: paket implementasi per milestone
