# Wireframe Prompts — TraceSpec

## Prompt: Spec Workspace

Create a low-fidelity responsive web-app workspace for TraceSpec, an AI product planning tool. The screen lets a solo builder inspect a PRD linked to user flows, screens, tasks, tests, assumptions, and risks. Use a left document outline, a central Markdown-like document area, and a right traceability panel. Show clickable ID chips such as FR-03, FLOW-02, SCR-04, TASK-09, and TEST-08. Include Draft status, a visible [TRACE GAP] warning state, revision history, and a primary action "Generate Build Packet". Prioritize clarity, hierarchy, keyboard accessibility, loading, error, and empty states. Do not include social feed, gamification, or unrelated analytics dashboards.

## Prompt: Change Impact

Create a low-fidelity responsive screen for a Change Impact Analysis. Show the change request, before/after scope, affected PRD sections, requirements, flows, screens, tasks, tests, risks, version recommendation, and actions: Approve revision, Defer to Phase 2, Reject. Make high-impact warnings obvious and provide a clear diff-like hierarchy.
