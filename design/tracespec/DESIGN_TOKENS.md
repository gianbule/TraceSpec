# Design Tokens — TraceSpec

## Semantic colors
- `status.draft`: neutral
- `status.ready`: blue
- `status.approved`: green
- `status.blocked`: red
- `status.warning`: amber
- `trace.problem`: violet
- `trace.requirement`: blue
- `trace.flow`: teal
- `trace.screen`: pink
- `trace.task`: orange
- `trace.test`: green

## UI rules
- Monospace treatment for IDs and code/path references.
- Document text remains readable before visual density.
- Use color with text labels/icons; never color alone for state.
