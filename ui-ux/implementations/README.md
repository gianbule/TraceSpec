# Implementations — TraceSpec UI

Folder ini berisi implementasi HTML/CSS/JS nyata untuk screen TraceSpec.

## Files

- `spec-workspace.html`: implementasi Spec Workspace (SCR-UI-03)

## Cara pakai

1. Buka `spec-workspace.html` di browser.
2. Explore layout, interactions, dan traceability panel.
3. Adapt untuk proyek lain atau integrasikan dengan backend/API.

## Tech stack

- HTML5 + CSS3 (vanilla)
- JavaScript minimal untuk interaksi (scroll to section, chip navigation)
- Menggunakan `design-tokens.css` dari folder parent
