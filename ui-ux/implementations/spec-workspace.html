2. Problem

P-01 — Planning AI coding terfragmentasi

Solo builder dan tim kecil sering langsung coding dari ide atau satu prompt besar. PRD, desain, task, dan test tidak terhubung; ketika requirement berubah, dampaknya tidak jelas.

3. Target User

  • PERSONA-01: Solo builder — Mengubah ide menjadi rencana build yang terarah
  • PERSONA-02: Founder non-teknis — Menjelaskan produk ke developer/agent
  • PERSONA-03: AI-first developer — Memberi konteks kecil dan akurat ke coding agent

4. Goals dan Non-Goals

  • G-01: Menghasilkan blueprint MVP yang jelas dari ide
  • G-02: Mengurangi gap antara PRD dan implementasi

5. Requirements

FR-01 Idea-to-MVP discovery

Sistem harus menerima ide bebas, mengekstrak problem, user, outcome, platform, constraint, dan mengajukan maksimal tujuh pertanyaan klarifikasi prioritas.

P-01 G-01 FLOW-01 SCR-01

FR-02 Challenge Mode

Sistem harus menghasilkan core problem, hypothesis, scope MVP, non-goals, risky assumptions, alternative sederhana, dan rekomendasi approve/revise/defer sebelum PRD final.

FR-03 Traceable PRD

Sistem harus membuat PRD dengan ID stabil untuk problem, assumption, goal, metric, story, requirement, flow, screen, feature, task, test, dan decision.
