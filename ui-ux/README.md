# UI/UX — TraceSpec

Folder ini menyimpan spesifikasi UI/UX untuk TraceSpec: user flows, screen inventory, wireframes, design tokens, dan komponen dasar.

## Struktur

- `user-flows.md`: alur pengguna inti
- `screen-inventory.md`: daftar screen dan state
- `wireframes/`: spesifikasi wireframe per screen
- `design-tokens.css`: design tokens (color, type, spacing)
- `components/`: contoh komponen HTML/CSS

## Cara pakai

1. Baca `user-flows.md` untuk memahami journey utama.
2. Lihat `screen-inventory.md` untuk overview screen dan state.
3. Buka `wireframes/[screen].md` untuk detail layout dan konten.
4. Gunakan `design-tokens.css` sebagai dasar implementasi visual.
5. Komponen di `components/` dapat dijadikan starting point untuk UI kit.
