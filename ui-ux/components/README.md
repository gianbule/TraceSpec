# Components — TraceSpec

Folder ini berisi contoh komponen HTML/CSS yang dapat dijadikan starting point untuk UI kit.

## Files

- `status-badge.html`: contoh status badges (Draft, Ready, Approved, Blocked)
- `trace-chips.html`: contoh traceability chips (P-01, FR-01, FLOW-01, dll.)
- `buttons.html`: contoh tombol (primary, secondary, danger)
- `code-block.html`: contoh code block untuk agent prompt

## Cara pakai

1. Buka file HTML di browser.
2. Inspect struktur dan style.
3. Adapt ke framework CSS atau design system Anda.

## Dependencies

Komponen menggunakan `design-tokens.css` di folder parent. Pastikan path CSS benar saat mengintegrasikan.
