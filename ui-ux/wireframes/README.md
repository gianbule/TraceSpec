# Wireframes — TraceSpec

Folder ini berisi spesifikasi wireframe untuk setiap screen utama.

## Files

- `dashboard.md`: overview proyek dan status
- `spec-workspace.md`: PRD viewer dengan traceability panel
- `build-packet-viewer.md`: detail build packet dan agent prompt
- `change-impact.md`: change impact analysis

## Cara pakai

Setiap file berisi:
- Layout structure
- Content sections
- Interactions
- States

Gunakan specs ini sebagai brief untuk Figma, UX Pilot, atau implementasi HTML/CSS.
